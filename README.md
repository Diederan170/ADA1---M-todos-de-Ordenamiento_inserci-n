# Ordenamiento por Inserción: Calificaciones

Programa interactivo en Python que solicita las calificaciones de un grupo de estudiantes (en una escala de 0 a 100) y las acomoda de menor a mayor.

## ¿Cómo funciona?
El programa toma una calificación a la vez y la compara hacia atrás con las que ya están acomodadas. Va recorriendo hacia la derecha las calificaciones más altas para abrir espacio e insertar la nueva calificación en el lugar exacto que le corresponde.

## Requisitos
* Tener instalado **Python 3**.

## Cómo ejecutarlo
1. Abre una terminal en la carpeta donde guardaste el archivo.
2. Ejecuta el comando:
   ```bash
   python ordenamiento_insercion.py
3. Indica cuántas calificaciones vas a capturar (mínimo 2) y escribe cada calificación una por una.
